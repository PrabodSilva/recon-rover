# Scope and Ethics

## What this tool does
Recon Rover listens to the beacon frames that access points broadcast
publicly and continuously. It records each network's name, hardware address,
channel, signal strength, and advertised security setting.

## What it does NOT do
- It does not connect to, log into, or authenticate against any network.
- It does not capture, store, or read the contents of anyone's traffic.
- It does not attempt to recover, crack, or bypass any password.
- It does not jam, deauthenticate, or interfere with any network or device.

## The rule
Reading a public announcement is observation. Touching the network is
intrusion. This tool stays entirely on the observation side.

## Testing scope
This tool was tested only on my own home network and my own devices.

## Legal note
In Sri Lanka, unauthorised access to a computer system is an offence under the
Computer Crimes Act No. 24 of 2007. This tool is designed to stay within the
law by only observing public broadcasts. Anyone using it elsewhere should get
written permission from the network owner first.

## Published data
All network names in screenshots and documentation are my own or have been
redacted.
